# Bash

## Переменные

Переменные в Bash используются для хранения значений.

Для обращения к переменной используется `$`.

```bash
echo "$HOME"
```

`env` показывает переменные окружения, доступные в текущем окружении.

```bash
env
```

### HOME

`$HOME` содержит путь к домашней директории текущего пользователя.

```bash
echo "$HOME"
```

Например:

```text
root     → /root
user     → /home/user
```

Поэтому команды:

```bash
cd ~
cd "$HOME"
```

обычно приводят в домашнюю директорию текущего пользователя.

## Командная строка

Prompt - это часть терминала, которая показывает информацию о текущем пользователе и директории.

Например:

```text
root@server:~#
```

Здесь:

```text
root       пользователь
server     имя компьютера
~          текущая директория
#          пользователь root
```

Для обычного пользователя обычно используется `$`:

```text
user@server:~$
```

Обычно `#` используется для root, а `$` - для обычного пользователя. Но prompt можно изменить, поэтому по одному символу нельзя точно определить права.

---

## PS1

`PS1` определяет внешний вид основного prompt Bash.

Например:

```bash
PS1=">>> "
```

После этого prompt будет выглядеть так:

```text
>>>
```

Изменение через команду действует только в текущей сессии.

Если обычный prompt настроен в `~/.bashrc`, его можно восстановить, заменив текущую оболочку новым экземпляром интерактивного Bash:

```bash
exec bash
```

---

## .bashrc

`.bashrc` - файл конфигурации Bash, который используется для настройки интерактивной оболочки.

Например, можно изменить его:

```bash
nano ~/.bashrc
```

После изменения файла применить настройки в текущей оболочке:

```bash
source ~/.bashrc
```

То же самое можно записать как:

```bash
. ~/.bashrc
```

## &&

`&&` позволяет выполнить следующую команду только в случае успешного выполнения предыдущей.

```bash
command1 && command2
```

Например:

```bash
mkdir test && cd test
```

Если `mkdir test` завершится успешно, выполнится `cd test`.

---

## |

`|` называется pipe (конвейер).

Он передаёт стандартный вывод одной команды на стандартный ввод другой команды.

```bash
command1 | command2
```

Например:

```bash
ls /etc | grep ssh
```

Здесь вывод `ls` передаётся программе `grep`, которая оставляет строки, содержащие `ssh`.

`|` и `&&` выполняют совершенно разные задачи:

```text
&&  → выполнить следующую команду при успешном завершении предыдущей

|   → передать вывод одной команды другой команде
```
