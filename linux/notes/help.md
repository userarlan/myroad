# Справка и документация

## man

`man` показывает руководство по команде или другому объекту системы.

```bash
man COMMAND
```

Например:

```bash
man ls
```

В руководстве можно найти описание команды, её параметры и примеры использования.

## Поиск по описанию

`man -k` ищет страницы руководства по ключевому слову в их кратком описании.

```bash
man -k "keyword"
```

Например:

```bash
man -k network
```

## Поиск информации о странице

`man -f` показывает краткое описание команды и список найденных страниц руководства с соответствующим именем.

```bash
man -f COMMAND
```

Например:

```bash
man -f printf
```

## whatis

`whatis` выводит краткое описание команды.

```bash
whatis COMMAND
```

Например:

```bash
whatis ls
```

## Навигация внутри man

При открытом руководстве используются команды `less`.

```text
g       перейти в начало
G       перейти в конец
/текст  найти текст
n       перейти к следующему совпадению
N       перейти к предыдущему совпадению
q       выйти
```

Поиск:

```text
/keyword
```

После ввода `/keyword` и нажатия `Enter` `man` найдёт первое совпадение.

## Секции man

Руководства разделены на секции. Основные секции:

```text
1   Пользовательские команды
2   Системные вызовы
3   Библиотечные функции
4   Специальные файлы и устройства
5   Форматы файлов и соглашения
6   Игры
7   Разное
8   Административные команды
```

Если у одного имени есть страницы в нескольких секциях, можно указать нужную секцию:

```bash
man 5 passwd
```
