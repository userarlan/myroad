# Навигация

## Текущая директория

`pwd` - показывает путь к текущей рабочей директории.

```bash
pwd
```

## cd

`cd` - используется для перехода в другую директорию.

```bash
cd /home
cd Documents
```

### Родительская директория

`..` обозначает родительскую директорию.

```bash
cd ..
cd ../..
cd ../../var/log
```

Каждый `..` поднимает на один уровень вверх.

### Корневая директория

`/` - корневая директория файловой системы.

```bash
cd /
```

### Домашняя директория

`~` обозначает домашнюю директорию текущего пользователя.

```bash
cd ~
```

Переменная `$HOME` содержит путь к домашней директории текущего пользователя.

```bash
cd "$HOME"
```

Для пользователя `root` это обычно `/root`, для обычного пользователя - `/home/<имя_пользователя>`.

### Предыдущая директория

`cd -` возвращает в предыдущую рабочую директорию.

```bash
cd -
```

## Абсолютный и относительный путь

**Абсолютный путь** начинается с корневой директории `/` и указывает полный путь к объекту.

```bash
cd /home/user/Documents
```

**Относительный путь** указывается относительно текущей директории.

```bash
cd Documents
cd ../Documents
```

## Основные обозначения

```text
/       корневая директория
~       домашняя директория текущего пользователя
..      родительская директория
.       текущая директория
cd -    предыдущая директория
```
