# Работа с файлами и директориями

## mkdir

`mkdir` - создаёт директорию.

```bash
mkdir directory
```

Для создания вложенных директорий используется `-p`:

```bash
mkdir -p parent/child/grandchild
```

## touch

`touch` - создаёт пустой файл, если его не существует.

```bash
touch file.txt
```

Если файл уже существует, `touch` обновляет его временную метку.

## mv

`mv` - перемещает или переименовывает файлы и директории.

### Перемещение

```bash
mv file.txt /home/user/Documents/
```

### Переименование

```bash
mv old-name.txt new-name.txt
```

Если указанная директория назначения существует, объект перемещается в неё.

Если второго аргумента с таким именем не существует, файл может быть переименован.

### Перезапись

Если файл назначения уже существует, `mv` по умолчанию может заменить его содержимое исходным файлом.

Например:

```text
file1.txt → "Привет"
file2.txt → "Мир"
```

```bash
mv file1.txt file2.txt
```

После выполнения `file1.txt` исчезнет, а `file2.txt` будет содержать:

```text
Привет
```

Чтобы случайно не перезаписать существующий файл, можно использовать:

```bash
mv -i file1.txt file2.txt
```

Ключ `-i` запросит подтверждение перед перезаписью.

## Основные команды

```text
mkdir    создать директорию
touch    создать файл
mv       переместить или переименовать
```
