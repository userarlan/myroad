# Сеть

| Команда      | Назначение                                 | Пример       |
| ------------ | ------------------------------------------ | ------------ |
| `ip addr`    | Показать сетевые интерфейсы и IP-адреса    | `ip addr`    |
| `ip link`    | Показать сетевые интерфейсы и их состояние | `ip link`    |
| `ifconfig`   | Показать информацию о сетевых интерфейсах  | `ifconfig`   |
| `netstat -i` | Показать статистику сетевых интерфейсов    | `netstat -i` |

## Полезные ключи

| Ключ | Значение                                       |
| ---- | ---------------------------------------------- |
| `-i` | Режим или информация, связанная с интерфейсами |
| `-a` | Все доступные объекты / информация             |
