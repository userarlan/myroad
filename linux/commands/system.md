# Система

| Команда      | Назначение                                              | Пример       |
| ------------ | ------------------------------------------------------- | ------------ |
| `lsblk`      | Показать блочные устройства и диски                     | `lsblk`      |
| `df -h`      | Показать свободное и занятое место на файловых системах | `df -h`      |
| `du -h`      | Показать размер файлов и директорий                     | `du -h`      |
| `ncdu`       | Интерактивно посмотреть, что занимает место на диске    | `ncdu`       |
| `tree /dev/` | Показать структуру директории `/dev/`                   | `tree /dev/` |
| `htop`       | Интерактивно посмотреть процессы и нагрузку на систему  | `htop`       |
| `free`       | Показать использование оперативной памяти               | `free`       |
| `free -h`    | Показать использование памяти в удобном формате         | `free -h`    |
| `uname -a`   | Показать информацию о системе и ядре                    | `uname -a`   |
| `uptime`     | Показать время работы системы и нагрузку                | `uptime`     |

## Полезные ключи

| Ключ | Значение                                   |
| ---- | ------------------------------------------ |
| `-h` | Удобный для чтения формат (human-readable) |
| `-a` | Все объекты / информация обо всех объектах |
| `-l` | Подробный формат (long)                    |
