# Навигация

| Команда  | Назначение                        | Пример        |
| -------- | --------------------------------- | ------------- |
| `pwd`    | Показать текущую директорию       | `pwd`         |
| `cd DIR` | Перейти в директорию              | `cd /var/log` |
| `cd ..`  | Перейти на уровень выше           | `cd ..`       |
| `cd -`   | Вернуться в предыдущую директорию | `cd -`        |
| `cd ~`   | Перейти в домашнюю директорию     | `cd ~`        |
| `cd /`   | Перейти в корень файловой системы | `cd /`        |
