# Справка

| Команда          | Назначение                            | Пример           |
| ---------------- | ------------------------------------- | ---------------- |
| `man COMMAND`    | Открыть руководство по команде        | `man ls`         |
| `man -k KEYWORD` | Найти страницы man по ключевому слову | `man -k network` |
| `man -f COMMAND` | Показать краткое описание команды     | `man -f printf`  |
| `whatis COMMAND` | Показать краткое описание команды     | `whatis ls`      |

## Навигация в man

| Клавиша  | Действие              |
| -------- | --------------------- |
| `g`      | Перейти в начало      |
| `G`      | Перейти в конец       |
| `/текст` | Поиск текста          |
| `n`      | Следующее совпадение  |
| `N`      | Предыдущее совпадение |
| `q`      | Выйти                 |
